# Engineering Standards

## Code Standards

Every file must include:

* Purpose
* Version
* Responsibility
* Author

---

## Design Rules

* One file = One responsibility
* Modular architecture
* Avoid circular dependencies
* Graph is the single source of truth
* Test every subsystem

---

## Worker Rules

Workers:

* Own a WorkerProfile
* Collaborate through the Collaboration Engine
* Learn continuously
* Gain experience
* Explain engineering decisions

---

## Executive Rules

Executive:

* Plans
* Prioritizes
* Delegates
* Evaluates

Executive never performs implementation.

---

## Documentation Standards

Every major subsystem must be documented.

Architecture changes must be reflected in the documentation.

---

## Quality Principles

* Readability over cleverness
* Maintainability over shortcuts
* Stability before expansion
* Engineering before automation

These standards apply to every future Graphify module.
